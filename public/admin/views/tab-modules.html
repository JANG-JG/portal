📖 그누보드식 신규 서비스 플러그인 개발 가이드

JG Server는 선언형 모듈 매니페스트 아키텍처를 채택하여, 새 서비스를 만들 때 포털의 메인 HTML이나 관리자 코드를 전혀 수정할 필요가 없습니다.

🚀 3분 완성 신규 서비스 등록 절차:

  1. 서비스 개발: 새 폴더(예: car/)를 만들고 웹 앱을 개발합니다.
  2. 관리자 화면 작성: 서비스 폴더 안에 admin-embed.html을 생성합니다.
  3. 모듈 등록: 위 [+ 새 서비스 등록] 버튼을 눌러 ID, 이름, URL, 아이콘을 입력하면 포털과 관리자에 100% 자동 연동됩니다!
