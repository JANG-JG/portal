통합 기술 명세

JG 통합 포털 서버의 런타임, 프론트엔드/백엔드 프레임워크, 독립 데이터베이스 및 네트워크 보안 환경 명세입니다.

⚙️ 백엔드 & 런타임
  • Node.js v20 LTS (Express)
    포털(:3004), 혈압(:3000), 자산(:3003)
  • Python 3.11 (Flask & Gunicorn)
    실시간 뉴스(:5050) & 스케줄러
  • PM2 Production Process Manager
    4개 핵심 서비스 프로세스 자가 회복/관리
🎨 프론트엔드 & UI 스택
  • HTML5 Semantic Markup
  • Modern CSS3 (Flexbox & CSS Grid)
    모바일 반응형 & 통합 내비게이션 바
  • Pure Vanilla JavaScript (ES6+)
    무거운 프레임워크 없는 제로 종속성 렌더링
  • PWA Web App (Service Worker v2)
  • Chart.js (반응형 캔버스 시각화)
🗄️ 데이터베이스 스택
  • SQLite 3 독립 DB 아키텍처
    • health.db (혈압·병원·계정)
    • asset.db (자산·거래·환율)
    • briefing.db (뉴스·브리핑 로그)
  • 실시간 WAL 저널 & 원클릭 백업 지원
🛡️ 네트워크 & 보안 인프라
  • Cloudflare Zero Trust Tunnel
    외부 직접 포트 노출 차단 암호화 터널링
  • Nginx Reverse Proxy & SSL (TLS 1.3)
  • Cross-Subdomain JWT SSO Session
    SameSite=Lax, HttpOnly, Secure 쿠키
  • Helmet CSP (Content Security Policy)
